# FFXIV Dash

个人导航仪表盘：把常用网站、服务状态和自定义组件集中到一个页面。

## 主要功能

- **看板管理**：链接分组与小组件分组自由编排，卡片拖拽排序，分组可调整位置与列数
- **内置组件**：统计、PvP 地图、市场行情、售楼中心、倒数日、市场税率、待办、备忘（Markdown）、休息提醒（番茄钟）
- **搜索**：全局快捷键唤起，检索已保存的链接并直连搜索引擎
- **外观定制**：浅色 / 深色 / 跟随系统，八套主题（默认-浅色 / 默认-深色 / 苍穹 / 红莲 / 暗影 / 晓月 / 金曦 / 银海），逐主题可编辑背景与卡片外观
- **数据管理**：看板一键导出 / 导入 JSON
- **每日跳转**：设置常用链接，每天首次进入页面时自动打开

## 技术栈

| 类别 | 选择 |
| --- | --- |
| 框架 | React 19 + TypeScript |
| UI | Ant Design 6（`@ant-design/icons` 6） |
| 拖拽 | `@dnd-kit` |
| 构建 | Vite 8 |
| Markdown | `marked`（备忘卡） |
| 日期 | `dayjs`（日期控件） |
| 代码检查 | oxlint |

## 环境依赖

- Node.js >= 20.19（Vite 8 要求）
- pnpm

## 快速开始

```bash
pnpm install
pnpm dev        # 启动开发服务器
pnpm build      # 类型检查 + 生产构建（产物在 dist/）
pnpm lint       # 代码检查
pnpm preview    # 预览构建产物
```
