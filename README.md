# FFXIV Dash · 汇集的海风

一个《最终幻想14》主题的个人导航仪表盘：把常用网站、游戏内信息组件和自定义内容集中到一个页面。

## 主要功能

- **看板管理**：链接分组与组件分组自由编排；卡片拖拽排序，分组用表头按钮调整位置，每组的卡片列数可调（1–6）
- **内置组件**（14 个）：
  - 联网获取：物品价格、市场税率（减税城市 + 含税计算）、房屋售卖、公告活动、黄金的试炼、汇率
  - 纯本地：PvP 地图轮换、极光预报、倒数日、掷骰、进度（阶段式追踪）、待办（到点自动清零）、便签（Markdown，双击正文直接编辑）、休息提醒（番茄钟 + 系统通知）
- **链接管理**：新建时自动抓取页面标题 / 描述 / 图标；设置里可批量导入（每行一个，自动去重）；每个链接可设搜索缩写；图标支持图片地址或单字符
- **搜索**：`Tab` 或在页面空白处直接敲字唤起；检索已保存的链接（缩写优先命中），并可一键跳转自定义搜索引擎（默认百度、石之家、FF14 WIKI 等 8 个，设置里可增删、启停、排序）；支持直接 `Ctrl+V` 粘贴关键词
- **外观定制**：浅色 / 深色 / 跟随系统，八套主题（默认-浅色 / 默认-深色 / 苍穹 / 红莲 / 暗影 / 晓月 / 金曦 / 银海），逐主题可编辑背景与卡片外观，背景图可上传（图片本体存 IndexedDB，不进导出文件）
- **数据管理**：看板与设置（每日自动跳转 / 搜索引擎 / 外观）一键导出 / 导入 JSON，导入后可一键恢复导入前的数据
- **每日自动跳转**：设置常用链接，每天首次进入页面时自动打开（一天一次）
- **顶栏时钟**：问候语 + 本地时间 + 艾欧泽亚时间实时换算
- **关于面板**：项目用到的数据接口、参考资料与技术栈一览

每种组件类型有实例上限（全局计数，默认 20，信息卡类为 1），达到上限后不能再新建。

## 技术栈

| 类别 | 选择 |
| --- | --- |
| 框架 | React 19 + TypeScript |
| UI | Ant Design 6（`@ant-design/icons` 6） |
| 拖拽 | `@dnd-kit` |
| 构建 | Vite 8 |
| Markdown | `marked`（便签卡） |
| 日期 | `dayjs`（日期控件） |
| 代码检查 | oxlint |

## 环境依赖

- Node.js >= 20.19（Vite 8 要求）
- pnpm

## 快速开始

```bash
pnpm install
pnpm dev          # 启动开发服务器
pnpm build        # 类型检查 + 生产构建（产物在 dist/，部署在 /ffxiv-dash/ 子路径）
pnpm build:root   # 同上，但按根路径 / 部署构建
pnpm lint         # 代码检查
pnpm preview      # 预览构建产物
```
